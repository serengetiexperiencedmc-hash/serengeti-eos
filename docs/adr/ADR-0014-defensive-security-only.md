# ADR-0014 — Defensive security only

- Status: **accepted for Development**
- Date: 2026-08-21

## Decision

Cyber capabilities are monitoring, protection, authorised testing, and authorised incident response. No exploit development, offensive tooling, or attack payloads.

Security tests are **authorization and control tests**.

## Consequences

SOC features in Phase 3 integrate with defensive products; they do not re-create an attack platform.
