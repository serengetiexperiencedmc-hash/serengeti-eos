# I20.6 — Pending AI draft nav badge

**Increment:** I20.6  
**Server version:** `0.73.0-i20.6`  
**Autonomy:** Level 2 (Draft). Unpublished until a human accepts.

## Summary

The drafts list returns a **pending count** that does not change when status or type filters are applied. The commercial sidebar uses that count as the **AI Drafts** badge.

## API

`GET /v1/ai/drafts` now includes `pendingCount` — the number of pending drafts for the tenant, independent of `status` / `artefactType` filters.

Accept and discard remain human-only.

## UI

- Overview **AI Drafts** shows a terracotta badge when `pendingCount > 0`
- The drafts page shows the same pending count next to the filters

## Not included

- LLM providers
- Merge, email, owner-assign, or autonomous apply
- Opening the applied CRM record from an accepted draft
