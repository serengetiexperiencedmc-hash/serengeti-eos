# I3.21 — Allowlist dual-control digest email

Batched email summarizing pending SES allowlist dual-control approvals (respects I3.20 snooze/dismiss).

## API

`POST /v1/notifications/email/dispatch-allowlist-dual-digest`

Requires `notification:dispatch:email`. Sends to the caller’s principal email.

## Behaviour

- Outbox key `allowlist-dual-digest:{yyyy-mm-dd}:{email}` (one per principal per UTC day)
- Empty pending → skipped `none_pending`
- Redispatch same day → `already_dispatched`
- Template key `notif.approval.allowlist_dual_digest`
- Banner: `I3.21`
