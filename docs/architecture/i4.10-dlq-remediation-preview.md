# I4.10 — DLQ Remediation Workflow Statuses

**Increment:** I4.10  
**Server version:** `0.49.0-i4.10-i3.13`

## Summary

Manual DLQ lifecycle transitions (investigating → corrected / permanently_rejected → resolved / closed) via PATCH, plus Commercial UI action buttons.

## API

| Route | Purpose |
| --- | --- |
| PATCH `/v1/events/dlq/:id` | `{ status, owner?, remediation? }` |
| GET `/v1/events/dlq` | `increment: I4.10` |

Permission: `events:replay:outbox`. Invalid transitions → 400.

## UI

Events page — per-row remediation actions; replay for `failed` and `corrected`.
