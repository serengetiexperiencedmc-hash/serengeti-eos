# I4.24 — Stale DLQ SLA digest snooze / ack

**Increment:** I4.24  
**Server version:** `0.64.0-pg26-i3.26-i4.24`

## Summary

Snooze or acknowledge the stale DLQ SLA digest inbox item so it does not keep firing while ops works the missed cron.

## Behaviour

- **Snooze** hides inbox + blocks stale email until `snoozedUntil`
- **Ack** hides inbox + blocks stale email until the next digest last-run stamp
- Dispatching the digest clears the suppression

In-memory store (`notifDlqSlaDigestStaleSuppressions`). Postgres persist is a follow-up.

## API

| Route | Change |
| --- | --- |
| POST `…/dlq-sla-digest-stale/snooze` | `{ hours?: number }` default 24 |
| POST `…/dlq-sla-digest-stale/ack` | Stamp `acknowledgedAt` |
| GET `…/dlq-sla-digest-status` | Adds `suppression` |
