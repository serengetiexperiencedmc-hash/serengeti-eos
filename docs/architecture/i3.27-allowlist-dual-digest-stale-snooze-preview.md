# I3.27 — Allowlist stale snooze / ack

**Increment:** I3.27  
**Server version:** `0.65.0-pg27-i3.27-i4.25`

## Summary

Mirror I4.24: snooze or acknowledge the stale allowlist dual-control digest inbox item so it does not keep firing while ops works the missed cron.

## Behaviour

- **Snooze** hides inbox + blocks stale email until `snoozedUntil`
- **Ack** hides inbox + blocks stale email until the next digest last-run stamp
- Dispatching the digest clears the suppression

In-memory store (`notifAllowlistDualDigestStaleSuppressions`). Postgres persist is a follow-up.

## API

| Route | Change |
| --- | --- |
| POST `…/allowlist-dual-digest-stale/snooze` | `{ hours?: number }` default 24 |
| POST `…/allowlist-dual-digest-stale/ack` | Stamp `acknowledgedAt` |
| GET `…/allowlist-dual-digest-status` | Adds `suppression` |
