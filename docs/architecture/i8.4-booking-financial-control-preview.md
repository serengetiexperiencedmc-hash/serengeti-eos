## Objective

Give finance users a booking-centred control surface that shows **client revenue**, **supplier cost**, **margin**, **invoiced/paid/outstanding**, and invoice-type coverage, without typing a raw booking UUID.

## User / business purpose

I8 already creates quotes and deposit/progress/final invoices, but `/commercial/finance` is disconnected from the booking lifecycle: create actions require a pasted ID, and there is no booking-level distinction between contract value, supplier cost, and payment status. I8.4 is the Booking → Finance connection.

## Distinctions (required)

| Concept | Source |
| --- | --- |
| Client revenue | C9 `sellPrice` |
| Supplier cost | C6 cost sheet `totalCost` for the booking's programme/RFP (0 if none) |
| Margin | revenue − supplier cost (percent vs revenue) |
| Invoiced / paid | I8 invoices (non-void) |
| Outstanding | `computeFinanceOutstanding(revenue, paidTotal)` |
| Payment status | invoice statuses + recon exceptions |

## UI requirements

- `/commercial/finance` — select a booking from finance control list (not a free-text UUID)
- Summary cards for the selected booking: revenue, supplier cost, margin, outstanding
- Existing quote/invoice/payment/recon actions use the selected booking id
- Empty: no bookings; none selected
- Links: command center, operations workspace
- Nav label for existing Finance href: **Finance** (still `/commercial/finance`)

## Navigation

No new module. Update the existing Finance item label only.

## API

| Method | Path | Permission |
|--------|------|------------|
| GET | `/v1/finance/health` | `finance:read:invoice` (tenant-scoped; increment `I8.4`) |
| GET | `/v1/finance/control` | `finance:read:invoice` |
| GET | `/v1/finance/bookings/:bookingId/control` | `finance:read:invoice` |

Finance users may lack `booking:read:booking`. Control endpoints read C9 bookings in-process under finance permission (tenant-scoped). Do not require C9 list permission.

Wrong-tenant / unknown booking on the detail control path → 404. List omits other tenants.

Alice (`finance.member`) is an authorized reader. Partner fixture lacks `finance:read:invoice` → 403.

## Control item (no `tenantId`)

`bookingId`, `bookingCode`, `title`, `organizationId`, `status`, `currency`, `clientRevenue`, `supplierCost`, `marginAmount`, `marginPercent`, `invoicedTotal`, `paidTotal`, `outstandingTotal`, `quotesCount`, `invoicesCount`, `depositStatus`, `progressStatus`, `finalStatus`, `reconciliationExceptions`.

## Data / migration

No new tables. `079_i84_booking_financial_control.sql` — schema comment only.

## Workflow

Read-only rollup. Mutations remain I8 / I8.3.

## Failure semantics

| Condition | Result |
| --- | --- |
| Unauthenticated | 401 |
| Missing `finance:read:invoice` | 403 |
| Unknown / wrong-tenant booking (detail) | 404 |
| Empty list | 200 `{ items: [] }` |

## Acceptance criteria

1. Finance UI selects a live booking and shows revenue / cost / margin / outstanding.
2. Create quote/invoice actions use the selected booking, not a pasted UUID.
3. Health is tenant-scoped and permissioned.
4. Partner cannot read health or control (403).
5. Wrong-tenant booking control is 404.
6. Web typecheck passes.

## Tests

- Health 401/403, tenant-scoped counts
- Control list includes tenant bookings only
- Detail control 404 foreign id
- Margin/outstanding math from seeded booking + invoice + cost sheet
