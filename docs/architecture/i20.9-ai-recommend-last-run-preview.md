# I20.9 — Persist recommend last-run

**Increment:** I20.9  
**Server version:** `0.76.0-i20.9`  
**Autonomy:** Level 1 (Recommend) for the run snapshot. Drafts stay unpublished until a human accepts.

## Summary

Each successful recommend read upserts a **last-run** snapshot (provider, count, keys, time). The drafts page shows that snapshot **without** recording a new run.

## API

`GET /v1/ai/recommendations` records a run and returns `lastRun`.

`GET /v1/ai/recommendations/last-run` returns the stored snapshot or `null`. It does not write.

Keys only — no PII. Dual-write / hydrate via `065_i209_ai_recommend_runs.sql`.

## UI

- `/commercial/ai` shows last recommend time, key count, and provider
- Dashboard AI panel shows the run from the recommend response

## Not included

- LLM providers
- Merge, email, owner-assign, or autonomous apply
- Full recommend history
