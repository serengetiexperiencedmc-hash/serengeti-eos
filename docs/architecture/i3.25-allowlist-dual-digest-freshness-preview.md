# I3.25 — Allowlist dual digest last-run freshness

**Increment:** I3.25  
**Server version:** `0.63.0-pg25-i3.25-i4.23`

## Summary

Mark the allowlist dual-control digest last-run as stale when it is missing or older than a threshold (mirrors I4.22).

## Threshold

`EOS_ALLOWLIST_DUAL_DIGEST_STALE_HOURS` (default **26** — a daily job plus slack).

Never-run counts as stale. Shared helper: `digestLastRunFreshness(..., envKey)`.

## API

| Route | Change |
| --- | --- |
| GET `…/allowlist-dual-digest-status` | Adds `freshness` |
| GET `…/email/health` | Adds `allowlistDualDigestFreshness` |

## freshness shape

```json
{ "stale": true, "neverRun": true, "ageHours": null, "thresholdHours": 26 }
```

## UI

Commercial Notifications — rose banner when the dual-control digest is stale.
