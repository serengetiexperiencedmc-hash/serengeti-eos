# I4.23 — Stale DLQ SLA digest inbox / email escalation

**Increment:** I4.23  
**Server version:** `0.63.0-pg25-i3.25-i4.23`

## Summary

When the DLQ SLA digest last-run is stale or never-run, surface an urgent inbox item and allow ops to fan out a same-day email alert.

## Inbox

Key `dlq-sla-digest-stale:{yyyy-mm-dd}` (UTC day) so the item can reappear after dismiss on the next day. Cleared automatically once a fresh digest last-run exists.

## API

| Route | Change |
| --- | --- |
| POST `…/dispatch-dlq-sla-digest-stale` | Email digest recipients; skip `not_stale` / `already_dispatched` |
| GET `/v1/notifications` | Includes stale-digest item when freshness is stale |

Email keys: `dlq-sla-digest-stale:{day}:{email}`. Recipients reuse I4.17 digest aliases.

## UI

Commercial Events — **Escalate stale digest** (enabled only when freshness is stale).
