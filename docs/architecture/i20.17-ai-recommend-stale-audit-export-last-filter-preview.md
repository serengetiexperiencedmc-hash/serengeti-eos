# I20.17 — Persist last-used recommend audit export filter

**Increment:** I20.17  
**Server version:** `0.84.0-i20.17`  
**Autonomy:** Level 1 (Recommend) snapshot only.

## Summary

Remember the last successful stale-recommend audit export filter (`action` / `since` / `until`) per tenant + principal. Dual-write when `EOS_DATABASE_URL` / `dbPool` is set, and hydrate on API startup. Last-run GET echoes `lastFilter` without recording a new recommend run.

## Migration

`068_i2017_ai_recommend_stale_audit_export_last_filter.sql` — table `ai_recommend_stale_audit_export_last_filter` (PK `tenant_id, principal_id`).

## Behaviour

- Successful stale export awaits `persistAiRecommendStaleAuditExportLastFilter`
- Invalid action / window does not persist
- Last-run and last-run export still do not record a new recommend run
- Commercial AI Drafts prefills action / since / until from `lastFilter`
