# I4.9 — DLQ / Replay Commercial UI

**Increment:** I4.9  
**Server version:** `0.47.0-i4.9-pg12`

## Summary

Commercial Event Infrastructure page lists tenant dead letters and supports request + execute replay against existing I4 HTTP APIs.

## API (increment banner)

| Route | Purpose |
| --- | --- |
| GET `/v1/events/dlq` | List DLQ (`increment: I4.9`) |
| POST `/v1/events/replay/request` | Request replay |
| POST `/v1/events/replay/:id/execute` | Execute replay |

Permissions unchanged: `events:read:dlq`, `events:replay:outbox`.

## UI

`/commercial/events` — DLQ table with multi-select + Replay selected; NATS lag retained below.
