# I20.12 — Stale recommend snooze / ack

**Increment:** I20.12  
**Server version:** `0.79.0-i20.12`  
**Autonomy:** Level 1 (Recommend) snapshot only. Does not record a new run.

## Summary

Snooze or acknowledge a stale recommend last-run so the banner does not keep firing while ops works the missed snapshot.

## Behaviour

- **Snooze** hides the stale banner until `snoozedUntil` (default 24h)
- **Ack** hides the stale banner until the next recommend last-run stamp
- Recording a new recommend run clears the suppression
- Freshness stays truthful (`stale` / `neverRun` unchanged)

In-memory store (`aiRecommendStaleSuppressions`), scoped to tenant + principal. Postgres persist is a follow-up.

## API

| Route | Change |
| --- | --- |
| POST `/v1/ai/recommendations/last-run/stale/snooze` | `{ hours?: number }` default 24 |
| POST `/v1/ai/recommendations/last-run/stale/ack` | Stamp `acknowledgedAt` |
| GET `/v1/ai/recommendations/last-run` | Adds `suppression`, `suppressed` |
| GET `/v1/ai/recommendations/last-run/export` | Adds the same fields |
| GET `/v1/ai/recommendations` | Returns `suppression: null` after restamp |

Snooze/ack require `ai:write:draft`. Unknown `hours` returns `400` (`invalid_hours`). Last-run and export remain read-only.
