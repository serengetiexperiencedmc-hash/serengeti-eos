# I4.21 — DLQ SLA digest last-run export / ops dashboard

**Increment:** I4.21  
**Server version:** `0.61.0-pg23-i3.23-i4.21`

## Summary

CSV/JSON export of the I4.19/I4.20 last-run stamp plus outbox analytics for ops dashboards.

## API

| Route | Purpose |
| --- | --- |
| GET `/v1/notifications/email/dlq-sla-digest-status/export` | `?format=json\|csv` |
| GET `/v1/notifications/email/health` | Adds `dlqSlaDigestLastRun` |
| POST `/v1/notifications/email/dispatch-dlq-sla-digest` | Banner `I4.21` |

## Export row

`tenantId, day, lastRunAt, lastRunByPrincipalId, breachedCount, dispatchedCount, skippedCount, recipientCount, outboxDigestCount, outboxSent, outboxQueued, outboxFailed`

Empty last-run still returns a zeroed row so schedulers can alert on “never run”.

## UI

Commercial Events — last-run line, dispatch digest, export CSV.
