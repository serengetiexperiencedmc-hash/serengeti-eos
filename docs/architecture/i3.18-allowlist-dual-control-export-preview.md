# I3.18 — Allowlist dual-control audit export

Extends allowlist list/export with dual-control audit fields and filters.

## API

- `GET /v1/notifications/email/allowlist?dualControlStatus=pending|approved|not_required`
- `GET /v1/notifications/email/allowlist/export?format=csv|json&pendingOnly=1&dualControlStatus=…`

## Response

- CSV includes `sesApprovalRequestedByPrincipalId`
- JSON/CSV include `pendingCount`, `approvedCount`, `notRequiredCount`
- `increment: "I3.18"`
