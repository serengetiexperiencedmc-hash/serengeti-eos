# I4.4 — NATS Consumer Offset Persistence

**Increment:** I4.4  
**Server version:** `0.37.0-i3.6-i4.4-pg5`

## Summary

Persists JetStream consumer stream sequence per tenant/consumer/stream and exposes offset listing plus bounded stream replay for Dev/Test.

## Persistence

| Layer | Change |
| --- | --- |
| Migration | `042_i44_nats_consumer_offsets.sql` |
| Facade | `persistence/nats-offsets.ts` — record, persist, hydrate |
| Consumer | `events/nats-consumer.ts` — records offset after successful process |
| Replay | `events/nats-replay.ts` — `listNatsConsumerOffsets`, `replayNatsStreamFromSeq` |
| Startup | `main.ts` — `hydrateNatsConsumerOffsets` |

## API

| Route | Permission | Purpose |
| --- | --- | --- |
| `GET /v1/events/consumers/nats/offsets` | `events:read:operations` | List stored offsets |
| `POST /v1/events/consumers/nats/replay` | `events:consume:outbox` | Replay from `fromSeq` (requires NATS env) |
