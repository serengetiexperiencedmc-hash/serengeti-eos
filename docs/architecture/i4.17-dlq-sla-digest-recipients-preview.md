# I4.17 — DLQ SLA digest recipient allowlist / ops aliases

Fan-out DLQ SLA digest emails to the dispatcher plus store/env ops aliases.

## API

- `GET/POST /v1/notifications/email/dlq-sla-digest-recipients`
- `POST /v1/notifications/email/dlq-sla-digest-recipients/:id/revoke`

## Env

`EOS_DLQ_SLA_DIGEST_RECIPIENTS=ops@…,oncall@…` (comma-separated, process-wide)

## Dedup

Outbox key `dlq-sla-digest:{yyyy-mm-dd}:{email}` (per recipient per UTC day). Banner: `I4.19`.
