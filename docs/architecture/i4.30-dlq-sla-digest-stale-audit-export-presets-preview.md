# I4.30 — Named DLQ stale-audit export presets

**Increment:** I4.30  
**Server version:** `0.97.0-i4.30`

## Summary

Save named tenant window presets for DLQ stale-audit export (`action` / `since` / `until`). In-memory this increment; persist is I4.31. Status GET echoes `presets` without persisting.

## API

| Method | Path | Perm | Behaviour |
| --- | --- | --- | --- |
| `GET` | `/v1/notifications/email/dlq-sla-digest-stale/export/presets` | `notification:read:email_outbox` | List tenant presets |
| `POST` | `/v1/notifications/email/dlq-sla-digest-stale/export/presets` | `notification:dispatch:email` | Create or upsert by name |
| `GET` | `/v1/notifications/email/dlq-sla-digest-stale/export?preset=` | `notification:read:email_outbox` | Apply a named preset |

Empty / whitespace / over-80-character names return `400` `invalid_name`. Unknown `preset` / `presetId` returns `404` `preset_not_found`. Query `action` / `since` / `until` override matching preset fields. Successful export still persists last-used filter (I4.29).

Presets are tenant-scoped and sanitized (no `tenantId` / `createdByPrincipalId`). Duplicate names match case-insensitively and keep the original id.

## UI

Commercial Events — **Audit preset** select, **Preset name**, **Save preset**. Selecting a preset fills action / since / until.
