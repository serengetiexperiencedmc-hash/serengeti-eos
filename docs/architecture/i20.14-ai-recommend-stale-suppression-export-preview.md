# I20.14 — Recommend stale suppression export / audit

**Increment:** I20.14  
**Server version:** `0.81.0-i20.14`  
**Autonomy:** Level 1 (Recommend) snapshot only.

## Summary

Keep an in-memory audit of snooze / ack / clear for the stale recommend last-run banner, and export it as CSV/JSON. Last-run and last-run export do not record a new recommend run.

## API

| Route | Change |
| --- | --- |
| GET `/v1/ai/recommendations/last-run/stale/export` | `format=json\|csv`; requires `ai:read:recommend` |

CSV columns: `action,snoozedUntil,acknowledgedAt,createdAt,createdByPrincipalId`.

Unknown format returns `400` `invalid_format`.

A new recommend last-run appends `cleared` only when a suppression existed (every `GET /v1/ai/recommendations` restamps).

## UI

Commercial AI Drafts — **Export stale audit** next to **Export last-run**.
