# I20.18 — Named tenant recommend audit export presets

**Increment:** I20.18  
**Server version:** `0.85.0-i20.18`  
**Autonomy:** Level 1 (Recommend) snapshot only.

## Summary

Save named tenant window presets for stale-recommend audit export (`action` / `since` / `until`). In-memory this increment; persist is I20.19. Last-run GET echoes `presets` without recording a new recommend run.

## API

| Method | Path | Perm | Behaviour |
| --- | --- | --- | --- |
| `GET` | `/v1/ai/recommendations/last-run/stale/export/presets` | `ai:read:recommend` | List tenant presets |
| `POST` | `/v1/ai/recommendations/last-run/stale/export/presets` | `ai:write:draft` | Create or upsert by name |
| `GET` | `/v1/ai/recommendations/last-run/stale/export?preset=` | `ai:read:recommend` | Apply a named preset |

Empty / whitespace / over-80-character names return `400` `invalid_name`. Unknown `preset` / `presetId` returns `404` `preset_not_found`. Query `action` / `since` / `until` override matching preset fields. Successful export still persists last-used filter (I20.17).

Presets are tenant-scoped and sanitized (no `tenantId` / `createdByPrincipalId`). Duplicate names match case-insensitively and keep the original id.

## UI

Commercial AI Drafts — **Audit preset** select, **Preset name**, **Save preset**. Selecting a preset fills action / since / until.
