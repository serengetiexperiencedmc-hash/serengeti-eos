# I20.21 — Preset usage audit / last-used preset echo

**Increment:** I20.21  
**Server version:** `0.88.0-i20.21`  
**Autonomy:** Level 1 (Recommend) snapshot only.

## Summary

When a named stale-recommend audit export preset is applied, record an in-memory usage row and stamp the last-used preset per tenant + principal. Last-run GET echoes `lastPreset` and `usages` without recording a new recommend run. Persist is I20.22.

## API

| Method | Path | Perm | Behaviour |
| --- | --- | --- | --- |
| `GET` | `/v1/ai/recommendations/last-run` | `ai:read:recommend` | Echo `lastPreset` + `usages` |
| `GET` | `/v1/ai/recommendations/last-run/stale/export?preset=` | `ai:read:recommend` | Apply preset and append usage |
| `GET` | `/v1/ai/recommendations/last-run/stale/export/presets/usage` | `ai:read:recommend` | JSON/CSV usage export |

Export without a preset does not append usage. Unknown usage format returns `400` `invalid_format`. Usage rows are sanitized (no `tenantId` / `principalId`).

CSV columns: `presetId,presetName,createdAt`.

## UI

Commercial AI Drafts — last-run line shows **Last preset**; **Export preset usage**. Prefills the preset select from `lastPreset` when that id still exists.
