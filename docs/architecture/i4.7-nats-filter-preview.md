# I4.7 — Per-Tenant NATS Filter Subjects

**Increment:** I4.7  
**Server version:** `0.42.0-i4.7-c4-ui`

## Summary

Events publish to tenant-scoped JetStream subjects so durable consumers can filter a single tenant for true isolated lag.

## Subject layout

| Kind | Pattern |
| --- | --- |
| Publish | `{prefix}.{tenantId}.{eventType}` (dots in event type → `_`) |
| Tenant filter | `{prefix}.{tenantId}.>` |
| Platform (default) | `{prefix}.>` |

Example: `eos.events.11111111-1111-4111-8111-111111111111.crm_organization_created_v1`

## Consumer env

| Env | Purpose |
| --- | --- |
| `EOS_NATS_FILTER_TENANT` | Subscribe only to that tenant's filter subject |
| `EOS_NATS_FILTER_SUBJECT` | Explicit filter override |
| (default) | Platform observer on `{prefix}.>` |

Tenant durable name: `EOS_TENANT_{first16CompactUuid}`.

## Lag API

`GET /v1/events/consumers/nats/lag` now includes:

- `increment: I4.7`
- `tenantFilter.{subject,durableName,numPending,brokerLag}`
- `summary.tenantBrokerLag`
