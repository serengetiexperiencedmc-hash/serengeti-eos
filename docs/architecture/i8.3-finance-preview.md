# I8.3 Finance Automation — Preview

Increment **I8.3** adds final-invoice eligibility gates, one-click auto-create, and a consolidated SoD payment request queue.

## Kernel

- `packages/kernel/src/finance-final-invoice.ts`
  - `assessFinalInvoiceEligibility()` — requires deposit + progress fully paid, no existing final invoice
  - Returns `remainingAmount` when eligible

## Database

- `packages/db/migrations/033_i8_final_invoice_automation.sql` — schema comment (runtime-computed; no new tables)

## API

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/finance/bookings/:bookingId/final-invoice-eligibility` | Check auto-final readiness |
| POST | `/v1/finance/invoices/final/auto` | Create final invoice when eligible |
| GET | `/v1/finance/payment-requests` | List linked SoD payment requests with invoice context |

Health increment updated to **I8.3** with `pendingPaymentRequests` count.

## Eligibility rules

1. Deposit invoice exists and status is `paid`
2. Progress invoice exists and status is `paid`
3. No non-void final invoice exists
4. Remaining contract balance &gt; 0

## UI

- **`/commercial/finance`** — **Auto final** button (checks eligibility first)
- New **Payments** tab — pending SoD requests with approve & apply actions
- Manual **+ Final** still available for edge cases

## Future (Phase 1+)

Scheduled auto-final on booking close, email client on final issue, bank file export on approved payments.
