# I20.4 — Persist AI drafts

**Increment:** I20.4  
**Server version:** `0.71.0-i20.4`  
**Autonomy:** Level 2 (Draft). Unpublished until a human accepts.

## Summary

AI drafts are dual-written to Postgres when `EOS_DATABASE_URL` is set, and hydrated on API start. A restart no longer wipes pending, accepted, or discarded drafts. Accept/discard stay human-only. Memory-only mode is unchanged when Postgres is not configured.

## Persistence

Migration `064_i204_ai_drafts.sql` — table `ai_drafts`.

| Event | Write |
| --- | --- |
| Create / replay | upsert |
| Human accept | upsert (status, applied entity) |
| Human discard | upsert (status) |
| API start | hydrate by id |

Dual-write is fire-and-forget. Failed Postgres writes do not block the in-memory draft.

## Not included

- LLM providers
- Merge, email, owner-assign, or autonomous apply
- Changing who may accept
