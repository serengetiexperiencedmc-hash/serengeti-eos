# I3.7 — SES SNS Subscription Auto-Confirm

**Increment:** I3.7  
**Server version:** `0.40.0-i4.6-i3.7`

## Summary

When AWS SNS sends `SubscriptionConfirmation` to the SES webhook, EOS optionally fetches the `SubscribeURL` to confirm the subscription automatically.

## Behavior

- Default: enabled (`EOS_SES_AUTO_CONFIRM_SUBSCRIPTION` unset or `1`)
- Disable: `EOS_SES_AUTO_CONFIRM_SUBSCRIPTION=0` → returns `subscription_acknowledged` without fetch
- Only HTTPS URLs on `*.amazonaws.com` (or `.amazonaws.com.cn`) are accepted
- Webhook returns `subscription_confirmed` on successful fetch, or `subscription_acknowledged` when no URL / auto-confirm off

## Health

`GET /v1/notifications/email/health` includes `snsAutoConfirmSubscription: boolean`.
