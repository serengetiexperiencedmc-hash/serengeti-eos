# I4.16 — DLQ SLA escalation digest email

On-demand batched email summarizing open DLQ SLA breaches (respects I4.15 ack/snooze).

## API

`POST /v1/notifications/email/dispatch-dlq-sla-digest`

Requires `notification:dispatch:email` and `events:read:dlq`.

## Behaviour

- Outbox key `dlq-sla-digest:{yyyy-mm-dd}` (one digest per principal per UTC day)
- Empty breaches → skipped `none_breached`
- Redispatch same day → `already_dispatched`
- Template key `notif.operations.dlq_sla_digest`
- `increment: "I4.16"`
