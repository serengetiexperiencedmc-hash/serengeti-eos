# I3.16 — Allowlist SES Sync Notes

**Increment:** I3.16  
**Server version:** `0.53.0-i3.16-i4.13`

## Summary

When SES suppression sync finds an address that is also on the transactional allowlist, stamp `sesNotedAt` / `sesSyncNote` on the allowlist entry and return `allowlistSesNotes` in the sync response.

## API

| Route | Change |
| --- | --- |
| POST `/v1/notifications/email/suppressions/sync` | Adds `allowlistSesNotes`, `allowlistSesNoted` |
| GET allowlist / export | Includes SES note fields |

Migration `052_i316_allowlist_ses_notes.sql`.
