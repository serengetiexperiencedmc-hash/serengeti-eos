# I4.22 — DLQ SLA digest last-run freshness SLA

**Increment:** I4.22  
**Server version:** `0.62.0-pg24-i3.24-i4.22`

## Summary

Mark the DLQ SLA digest last-run as stale when it is missing or older than a threshold so ops can alert on missed cron.

## Threshold

`EOS_DLQ_SLA_DIGEST_STALE_HOURS` (default **26** — a daily job plus slack).

Never-run counts as stale.

## API

| Route | Change |
| --- | --- |
| GET `…/dlq-sla-digest-status` | Adds `freshness` |
| GET `…/dlq-sla-digest-status/export` | Adds freshness columns |
| GET `…/email/health` | Adds `dlqSlaDigestFreshness` |

## freshness shape

```json
{ "stale": true, "neverRun": true, "ageHours": null, "thresholdHours": 26 }
```
