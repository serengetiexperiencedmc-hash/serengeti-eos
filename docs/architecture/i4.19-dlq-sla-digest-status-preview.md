# I4.19 — DLQ SLA digest last-run stamp / status

Ops visibility into the last DLQ SLA digest dispatch plus outbox digest analytics.

## API

- `POST /v1/notifications/email/dispatch-dlq-sla-digest` — response includes `lastRun`
- `GET /v1/notifications/email/dlq-sla-digest-status` — `{ lastRun, analytics }`

## lastRun shape

```json
{
  "tenantId": "…",
  "day": "2026-08-22",
  "lastRunAt": "…",
  "lastRunByPrincipalId": "…",
  "breachedCount": 1,
  "dispatchedCount": 2,
  "skippedCount": 0,
  "recipientCount": 2
}
```

Stamped on every dispatch attempt (including `none_breached`). In-memory for now (dual-write later).

## analytics

- `outboxDigestCount` — outbox rows with key prefix `dlq-sla-digest:`
- `outboxByStatus` — counts by outbox status
