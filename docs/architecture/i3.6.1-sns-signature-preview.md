# I3.6.1 — SNS Signature Verification

**Increment:** I3.6.1  
**Server version:** `0.38.0-i3.6.1-i4.5-pg6`

## Summary

Production hardening for SES/SNS webhooks: verifies RSA-SHA1/SHA256 signatures against AWS signing certificates before processing bounce/complaint notifications.

## Behaviour

| Mode | When |
| --- | --- |
| Verify | SNS envelope includes `Signature` + `SigningCertURL` (default) |
| Skip | `EOS_SES_WEBHOOK_SKIP_SNS_VERIFY=1` (dev/test) |
| Direct payload | No SNS fields — allowed for local integration tests |

Signing cert URLs must match `https://sns.*.amazonaws.com(.cn)/*`. Certificates are cached in-memory for 1 hour.

## Health

`GET /v1/notifications/email/health` reports `snsSignatureVerification: true|false`.
