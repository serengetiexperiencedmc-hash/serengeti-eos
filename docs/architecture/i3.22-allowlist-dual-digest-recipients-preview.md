# I3.22 — Allowlist dual-control digest recipient aliases

Fan-out allowlist dual-control digest emails to the dispatcher plus store/env ops aliases (mirrors I4.17 DLQ digest recipients).

## API

- `GET/POST /v1/notifications/email/allowlist-dual-digest-recipients`
- `POST /v1/notifications/email/allowlist-dual-digest-recipients/:id/revoke`

## Env

`EOS_ALLOWLIST_DUAL_DIGEST_RECIPIENTS=approver@…,ops@…` (comma-separated)

## Dedup

Outbox key `allowlist-dual-digest:{yyyy-mm-dd}:{email}` (per recipient per UTC day). Banner: `I3.22`.
