# I20.7 — Open applied CRM record from an accepted draft

**Increment:** I20.7  
**Server version:** `0.74.0-i20.7`  
**Autonomy:** Level 2 (Draft). Unpublished until a human accepts.

## Summary

Accepted drafts include an **`appliedHref`** that opens the created CRM task or activity. The CRM page reads `?task=` or `?activity=`, switches tab, and highlights the row.

## API

`appliedHref` is computed on sanitize (not stored). It is only `/commercial/crm?task=<uuid>` or `/commercial/crm?activity=<uuid>`.

Pending drafts have no href. Accept and discard remain human-only.

## UI

- Accepted rows on `/commercial/ai` link **Open in CRM**
- CRM **Tasks** tab lists tasks so applied task drafts have a destination
- Focused row uses `id="crm-applied"`

## Not included

- LLM providers
- Merge, email, owner-assign, or autonomous apply
- Completing or cancelling tasks from the highlight
