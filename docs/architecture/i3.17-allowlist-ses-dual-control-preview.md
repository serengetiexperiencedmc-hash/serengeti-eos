# I3.17 — Allowlist SES Dual-Control for VIP Overrides

**Increment:** I3.17  
**Server version:** `0.55.0-i3.17-pg17-i4.15`

## Summary

When SES sync notes an allowlisted address (`sesNotedAt`), the entry enters `sesDualControlStatus: pending` and no longer bypasses suppressions until a second principal approves (`POST …/allowlist/:id/approve-ses`). Self-approval is forbidden.

## API

| Route | Purpose |
| --- | --- |
| POST `/v1/notifications/email/allowlist/:id/approve-ses` | Second-principal approval |
| GET `/v1/notifications/email/allowlist` | Banner `I3.17` + dual-control fields |
