# I20.16 — Recommend stale audit filters / export window

**Increment:** I20.16  
**Server version:** `0.83.0-i20.16`  
**Autonomy:** Level 1 (Recommend) snapshot only.

## Summary

Filter the I20.14 stale-recommend audit export by action and an inclusive `createdAt` window. Last-run and last-run export still do not record a new recommend run.

## API

| Query | Behaviour |
| --- | --- |
| `action=snooze\|ack\|cleared` | Keep matching audit rows |
| `since` / `until` | Inclusive ISO window on `createdAt` |

Unknown action returns `400` `invalid_action`. Unparseable or inverted window returns `400` `invalid_window`.

Response includes `filter: { action, since, until }`.

## UI

Commercial AI Drafts — action / since / until next to **Export stale audit**.
