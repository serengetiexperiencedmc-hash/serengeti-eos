# I3.14 — Suppression Allowlist / Transactional Override

**Increment:** I3.14  
**Server version:** `0.50.0-pg14-i3.14`

## Summary

Tenant allowlist for addresses that must receive mail even when actively suppressed (transactional override). Migration `050_i314_email_allowlist.sql`.

## Behaviour

`isEmailSuppressed` returns false when the recipient is on the active allowlist.

## API

| Route | Purpose |
| --- | --- |
| GET `/v1/notifications/email/allowlist` | List active entries |
| POST `/v1/notifications/email/allowlist` | `{ email, note? }` add/update |
| POST `/v1/notifications/email/allowlist/:id/revoke` | Soft-revoke |
