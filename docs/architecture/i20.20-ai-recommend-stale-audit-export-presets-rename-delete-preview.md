# I20.20 — Rename / delete recommend audit export presets

**Increment:** I20.20  
**Server version:** `0.87.0-i20.20`  
**Autonomy:** Level 1 (Recommend) snapshot only.

## Summary

Rename or delete a named tenant stale-recommend audit export preset. Writes await persist when `dbPool` is set. Last-run GET still echoes `presets` without recording a new recommend run.

## API

| Method | Path | Perm | Behaviour |
| --- | --- | --- | --- |
| `POST` | `/v1/ai/recommendations/last-run/stale/export/presets/:id/rename` | `ai:write:draft` | Rename by id |
| `DELETE` | `/v1/ai/recommendations/last-run/stale/export/presets/:id` | `ai:write:draft` | Delete by id |

Empty / whitespace / over-80-character names return `400` `invalid_name`. Unknown id returns `404` `preset_not_found`. A case-insensitive name clash with another tenant preset returns `409` `name_taken`.

## UI

Commercial AI Drafts — **Rename preset** and **Delete preset** next to **Save preset**.
