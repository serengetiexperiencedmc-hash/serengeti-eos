# I4.26 — Stale-digest suppression export / audit

**Increment:** I4.26  
**Server version:** `0.66.0-pg28-i3.28-i4.26`

## Summary

Keep an in-memory audit of snooze / ack / clear, and export it as CSV/JSON alongside the current suppression.

## API

| Route | Change |
| --- | --- |
| GET `…/dlq-sla-digest-stale/export` | `format=json\|csv` |

CSV columns: `action,snoozedUntil,acknowledgedAt,createdAt,createdByPrincipalId`.

Dispatching the digest appends `cleared`.
