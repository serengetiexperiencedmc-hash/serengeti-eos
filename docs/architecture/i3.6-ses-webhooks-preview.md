# I3.6 — SES Bounce/Complaint Webhooks

**Increment:** I3.6  
**Server version:** `0.37.0-i3.6-i4.4-pg5`

## Summary

Extends I3.5 SES transport with delivery feedback: SNS/SES bounce and complaint notifications update outbox status and append audit rows.

## Persistence

| Layer | Change |
| --- | --- |
| Migration | `041_i36_ses_delivery_events.sql` — outbox `bounced`/`complained`, `ses_message_id`, `notif_email_delivery_events` |
| Webhook | `notifications/ses-webhook.ts` — parse SNS envelope, match outbox by SES message ID or recipient |
| Transport | `ses-transport.ts` — returns SES `messageId`, adds EmailTags |
| Health | `getEmailAdapterHealth` reports `deliveryEventCount`, increment `I3.6` |

## API

| Route | Auth | Purpose |
| --- | --- | --- |
| `POST /v1/notifications/email/ses-webhook` | Optional `X-EOS-Webhook-Secret` (`EOS_SES_WEBHOOK_SECRET`) | Ingest SNS bounce/complaint |
| `GET /v1/notifications/email/delivery-events` | Bearer | List delivery events for tenant |
