# I3.2 Email Templates & SMTP Stub — Preview

Increment **I3.2** adds a template registry for notification emails and a configurable SMTP stub adapter.

## Kernel

- `packages/kernel/src/notification-template.ts`
  - `EmailTemplate`, `DEFAULT_EMAIL_TEMPLATES`, `resolveEmailTemplate()`, `listEmailTemplateKeys()`
- `notification-email.ts` — `buildEmailFromNotification()` uses template registry

## Database

- `packages/db/migrations/034_i3_email_templates.sql` — tenant-scoped template overrides

## API

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/notifications/email/templates` | List default + tenant templates |
| GET | `/v1/notifications/email/templates/:key/preview` | Render sample with `{{vars}}` |
| POST | `/v1/notifications/email/dispatch-digest` | Uses selected adapter + templates |

### Adapters (env `EOS_EMAIL_ADAPTER`)

| Value | Behavior |
| --- | --- |
| `dev-outbox` (default) | In-memory outbox (I3.1) |
| `smtp-stub` | No SMTP connection; records outbox with adapter `smtp-stub` |

Optional `EOS_SMTP_HOST` reported in health (not connected in Dev/Test).

- `/commercial/notifications` — template list panel + adapter badge
