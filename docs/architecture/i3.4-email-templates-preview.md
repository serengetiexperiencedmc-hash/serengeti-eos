# I3.4 Tenant Email Template Editor — Preview

Increment **I3.4** adds tenant-scoped template overrides with API persistence and a commercial UI editor.

## API

| Method | Path | Description |
| --- | --- | --- |
| GET | `/v1/notifications/email/templates` | List default + tenant templates |
| PUT | `/v1/notifications/email/templates/:key` | Upsert tenant override (subject, bodyText, optional bodyHtml) |
| GET | `/v1/notifications/email/templates/:key/preview` | Render sample with `{{vars}}` |

Health increment: `I3.4`.

## Persistence (PG.1 pattern)

When `EOS_DATABASE_URL` is set, tenant template overrides dual-write to `notif_email_templates` and hydrate on startup.

## UI

- `/commercial/notifications` — template selector, subject/body editor, save, live preview panel

## Future

- Rich HTML editor + WYSIWYG preview
- Template versioning and audit trail
- Production SMTP/SES dispatch using tenant overrides
