# I4.15 — DLQ SLA Acknowledge / Snooze

**Increment:** I4.15  
**Server version:** `0.55.0-i3.17-pg17-i4.15`

## Summary

Open DLQ rows past SLA can be acknowledged or snoozed. While acknowledged or snoozed, `slaBreached` is false and inbox `dlq-sla:*` items are suppressed. Expired snooze restores escalation.

## API

| Route | Purpose |
| --- | --- |
| POST `/v1/events/dlq/:id/sla-acknowledge` | Ack escalation |
| POST `/v1/events/dlq/:id/sla-snooze` | `{ hours }` or `{ until }` |
| POST `/v1/events/dlq/:id/sla-clear` | Clear ack/snooze |
