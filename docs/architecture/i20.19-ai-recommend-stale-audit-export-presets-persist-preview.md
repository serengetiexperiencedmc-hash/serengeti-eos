# I20.19 — Persist named recommend audit export presets

**Increment:** I20.19  
**Server version:** `0.86.0-i20.19`  
**Autonomy:** Level 1 (Recommend) snapshot only.

## Summary

Dual-write named tenant stale-recommend audit export presets when `EOS_DATABASE_URL` / `dbPool` is set, and hydrate on API startup. Invalid names / windows do not persist. Last-run GET still echoes `presets` without recording a new recommend run.

## Migration

`069_i2019_ai_recommend_stale_audit_export_preset.sql` — table `ai_recommend_stale_audit_export_preset` (PK `id`, unique `(tenant_id, lower(name))`).

## Behaviour

- Successful `POST …/stale/export/presets` awaits `persistAiRecommendStaleAuditExportPreset`
- Empty / invalid name or filter does not persist
- Hydrate log: `i2019_ai_recommend_stale_audit_export_preset_hydrate`
- Last-run and last-run export still do not record a new recommend run
