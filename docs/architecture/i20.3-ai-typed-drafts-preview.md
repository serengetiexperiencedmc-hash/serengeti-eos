# I20.3 — Typed AI draft artefacts

**Increment:** I20.3  
**Server version:** `0.70.0-i20.3`  
**Autonomy:** Level 2 (Draft). Unpublished until a human accepts.

## Summary

Draft type now follows the recommendation. Overdue CRM work becomes a **CRM activity** note, not another task. Other live recommendations still draft a **CRM task**. Nothing is written until a human accepts. The assistant still cannot merge, email, assign owners, or approve.

## Port

`packages/kernel/src/ai-draft.ts` — artefact types `crm_task` | `crm_activity`.

| Recommendation | Artefact |
| --- | --- |
| `crm.task.overdue` | `crm_activity` when an overdue task has a related org/contact; otherwise `crm_task` |
| `crm.duplicate.review` | `crm_task` |
| `crm.organization.missing_owner` | `crm_task` |
| `events.dlq_digest.stale` | `crm_task` |
| `notifications.allowlist_digest.stale` | `crm_task` |

Unknown keys, including `crm.merge.execute`, stay rejected.

## API

Same I20.2 routes. Accept applies through the existing human helpers:

- `crm_task` → `createTask()`
- `crm_activity` → `createActivity({ activityType: "follow_up" })`

AiAgent principals remain denied on `accept:*`.

## UI

Pending drafts show **CRM task draft** or **CRM activity draft**.

## Not included

- LLM providers (ADR-0008: `dev-rules` only)
- Merge, email, owner-assign, or proposal copy
- Autonomous apply (L3+)
- Persisted draft store
