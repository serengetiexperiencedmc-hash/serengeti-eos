# I4.11 — DLQ Owner Assignment & Dashboard Filters

**Increment:** I4.11  
**Server version:** `0.51.0-i4.11-i3.15`

## Summary

Assign/clear DLQ owners without a status transition; filter DLQ by owner, unassigned, and status.

## API

| Route | Purpose |
| --- | --- |
| GET `/v1/events/dlq?owner=&status=&unassigned=1` | Filtered list + `owners` facet |
| PATCH `/v1/events/dlq/:id` `{ owner }` | Owner-only assign (no `status`) |

## UI

Events — owner chips, status select, per-row owner Set control.
