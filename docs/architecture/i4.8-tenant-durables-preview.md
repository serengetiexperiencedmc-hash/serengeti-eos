# I4.8 — Auto-Provision Tenant NATS Durables

**Increment:** I4.8  
**Server version:** `0.43.0-i3.9-i4.8`

## Summary

On JetStream publish, EOS ensures a tenant-filtered durable consumer exists (`EOS_TENANT_*` + filter `{prefix}.{tenantId}.>`). Idempotent per process via an in-memory provisioned set.

## Env

| Env | Default | Purpose |
| --- | --- | --- |
| `EOS_NATS_AUTO_TENANT_DURABLES` | enabled | Set `0` to disable auto-provision |

## Code

- `ensureTenantDurableConsumer` in `events/nats-transport.ts`
- Called from `createNatsJetStreamTransport().publish`
