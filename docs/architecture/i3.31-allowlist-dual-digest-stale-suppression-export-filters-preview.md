# I3.31 — Allowlist stale-audit filters

**Increment:** I3.31  
**Server version:** `0.92.0-i3.31`

## Summary

Mirror I4.28: filter the I3.29 allowlist dual-digest stale audit export by action and an inclusive `createdAt` window. Rows stay tenant-scoped.

## API

`GET /v1/notifications/email/allowlist-dual-digest-stale/export`

| Query | Behaviour |
| --- | --- |
| `action=snooze\|ack\|cleared` | Keep matching audit rows |
| `since` / `until` | Inclusive ISO window on `createdAt` |

Unknown action returns `400` `invalid_action`. Unparseable or inverted window returns `400` `invalid_window`.

Response includes `filter: { action, since, until }`. Other tenants' audit rows are never included.

## UI

Commercial Notifications — action / since / until next to **Export stale audit**.
