# I20.22 — Persist preset usage / last-used preset

**Increment:** I20.22  
**Server version:** `0.89.0-i20.22`  
**Autonomy:** Level 1 (Recommend) snapshot only.

## Summary

When a named stale-recommend audit export preset is applied, dual-write the usage row and last-used preset when `EOS_DATABASE_URL` / `dbPool` is set, and hydrate both on API startup. Last-run GET still echoes `lastPreset` and `usages` without recording a new recommend run.

## Migration

`070_i2022_ai_recommend_stale_audit_export_preset_usage.sql`

- `ai_recommend_stale_audit_export_preset_usage` — PK `id`
- `ai_recommend_stale_audit_export_last_preset` — PK `tenant_id, principal_id`

## Behaviour

- Successful stale export with a resolved preset awaits persist of usage and last preset
- Export without a preset, or invalid action / window, does not persist usage or last preset
- Last-run, last-run export, and usage export still do not record a new recommend run
- Startup logs `i2022_ai_recommend_stale_audit_export_preset_usage_hydrate` and `i2022_ai_recommend_stale_audit_export_last_preset_hydrate`
