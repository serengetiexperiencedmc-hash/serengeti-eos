# I4.6 — Per-Tenant NATS Stream Lag

**Increment:** I4.6  
**Server version:** `0.40.0-i4.6-i3.7`

## Summary

Extends I4.5 lag metrics with per-tenant stream lag (`streamHeadSeq − lastStreamSeq`) and a bounded recent-message scan that counts tenant vs other-tenant envelopes in the last 50 stream sequences.

## API

`GET /v1/events/consumers/nats/lag` — permission `events:read:operations`

New fields:
- `offsets[].streamHeadSeq` — current JetStream head when NATS is connected
- `offsets[].tenantStreamLag` — messages on stream since tenant checkpoint
- `summary.maxTenantStreamLag` — max lag across tenant offsets
- `tenantIndex` — `{ scanned, tenantMessages, otherTenantMessages }` from recent scan

Degraded when `maxTenantStreamLag > 500` (in addition to I4.5 broker lag / staleness rules).

## Web UI

`/commercial/events` — tenant lag card + tenant index + lag column in offset table.
