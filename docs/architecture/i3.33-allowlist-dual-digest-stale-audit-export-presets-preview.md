# I3.33 — Named allowlist stale-audit export presets

**Increment:** I3.33  
**Server version:** `0.95.0-i3.33`

## Summary

Save named tenant window presets for allowlist stale-audit export (`action` / `since` / `until`). In-memory this increment; persist is I3.34. Status GET echoes `presets` without persisting.

## API

| Method | Path | Perm | Behaviour |
| --- | --- | --- | --- |
| `GET` | `/v1/notifications/email/allowlist-dual-digest-stale/export/presets` | `notification:read:email_outbox` | List tenant presets |
| `POST` | `/v1/notifications/email/allowlist-dual-digest-stale/export/presets` | `notification:dispatch:email` | Create or upsert by name |
| `GET` | `/v1/notifications/email/allowlist-dual-digest-stale/export?preset=` | `notification:read:email_outbox` | Apply a named preset |

Empty / whitespace / over-80-character names return `400` `invalid_name`. Unknown `preset` / `presetId` returns `404` `preset_not_found`. Query `action` / `since` / `until` override matching preset fields. Successful export still persists last-used filter (I3.32).

Presets are tenant-scoped and sanitized (no `tenantId` / `createdByPrincipalId`). Duplicate names match case-insensitively and keep the original id.

## UI

Commercial Notifications — **Audit preset** select, **Preset name**, **Save preset**. Selecting a preset fills action / since / until.
