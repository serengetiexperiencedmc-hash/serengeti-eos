# I3.8 — SES Configuration Set Event Routing

**Increment:** I3.8  
**Server version:** `0.41.0-pg8-i3.8`

## Summary

Attach an SES configuration set on send and route the full configuration-set event set through the existing SES webhook.

## Send path

Set `EOS_SES_CONFIGURATION_SET` — SES `SendEmail` includes `ConfigurationSetName`.

## Webhook events

| SNS / SES type | Delivery event | Outbox status |
| --- | --- | --- |
| Bounce | `bounce` | `bounced` |
| Complaint | `complaint` | `complained` |
| Delivery | `delivery` | `delivered` |
| Reject | `reject` | `rejected` |
| Open | `open` | unchanged (recorded only) |
| Click | `click` | unchanged (recorded only) |

Migration `046_i38_ses_config_set_events.sql` expands event-type and outbox status checks.
