# I3.20 — Dual-control reminder snooze / dismiss

Operators can snooze or dismiss SES allowlist dual-control inbox reminders (`allowlist-ses-dual:{id}`) without approving the override.

## API

- `POST /v1/notifications/email/allowlist/:id/reminder-snooze` — body `{ hours }` or `{ until }`
- `POST /v1/notifications/email/allowlist/:id/reminder-dismiss` — body `{ reason }` (required)
- `POST /v1/notifications/email/allowlist/:id/reminder-clear` — clears snooze/dismiss

## Behaviour

- Only when `sesDualControlStatus === "pending"`
- Snooze hides the reminder until `dualReminderSnoozeUntil`
- Dismiss hides until clear (or approval); stores `dualReminderDismissReason`
- Approval clears snooze/dismiss fields
- Migration `057_i320_allowlist_dual_reminder.sql`
