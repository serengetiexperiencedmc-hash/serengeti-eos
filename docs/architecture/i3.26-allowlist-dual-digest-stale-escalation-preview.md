# I3.26 — Allowlist stale inbox / email alert

**Increment:** I3.26  
**Server version:** `0.64.0-pg26-i3.26-i4.24`

## Summary

Mirror I4.23: when the allowlist dual-control digest last-run is stale or never-run, surface an urgent inbox item and allow ops to fan out a same-day email alert.

## Inbox

Key `allowlist-dual-digest-stale:{yyyy-mm-dd}` (UTC day). Cleared once a fresh digest last-run exists.

## API

| Route | Change |
| --- | --- |
| POST `…/dispatch-allowlist-dual-digest-stale` | Email digest recipients; skip `not_stale` / `already_dispatched` |
| GET `/v1/notifications` | Includes stale allowlist-digest item |

Email keys: `allowlist-dual-digest-stale:{day}:{email}`.
