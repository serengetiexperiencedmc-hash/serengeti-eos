# I3.10 — SES Account Suppression Sync

**Increment:** I3.10  
**Server version:** `0.45.0-i3.10-pg10`

## Summary

Tenant email suppressions sync with the SES account-level suppression list:

- Bounce / complaint / reject upserts best-effort `PutSuppressedDestination`
- Lift best-effort `DeleteSuppressedDestination`
- `POST .../suppressions/sync` pulls account destinations into the tenant list (`reason: bounce | complaint | ses_account`)

Disable with `EOS_SES_SUPPRESSION_SYNC=0`. Requires SES credentials (`EOS_SES_REGION` + keys as for I3.5).

## Persistence

Migration `048_i310_ses_suppression_sync.sql` — expands `notif_email_suppressions.reason` check to include `ses_account`.

## API

| Route | Auth | Purpose |
| --- | --- | --- |
| POST `/v1/notifications/email/suppressions/sync` | Bearer (`notification:dispatch:email`) | Import SES account suppressions |
| GET `/v1/notifications/email/suppressions` | Bearer | List active (`increment: I3.10`) |
| POST `/v1/notifications/email/suppressions/:id/lift` | Bearer | Lift local + best-effort SES remove |
