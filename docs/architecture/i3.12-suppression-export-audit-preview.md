# I3.12 — Suppression Export & Webhook Audit Trail

**Increment:** I3.12  
**Server version:** `0.48.0-i3.12-pg13`

## Summary

Export tenant email suppressions (JSON/CSV). Delivery-events list is the SES webhook audit trail with optional filters and raw payload.

## API

| Route | Purpose |
| --- | --- |
| GET `/v1/notifications/email/suppressions/export?format=json\|csv&includeLifted=` | Export suppressions |
| GET `/v1/notifications/email/delivery-events?eventType=&from=&to=&includePayload=` | Audit trail |
