# I3.11 — Email Delivery Analytics Dashboard

**Increment:** I3.11  
**Server version:** `0.46.0-pg11-i3.11`

## Summary

Tenant-scoped aggregates over SES delivery events, suppressions, and outbox status for Commercial notifications.

## API

| Route | Auth | Purpose |
| --- | --- | --- |
| GET `/v1/notifications/email/analytics?windowHours=168` | Bearer (`notification:read:email_outbox`) | Aggregate stats |
| GET `/v1/notifications/email/delivery-events` | Bearer | Recent events (`increment: I3.11`) |

Analytics payload: `deliveryEventsByType`, `suppressionsByReason`, `activeSuppressions`, `liftedSuppressions`, `outboxByStatus`, `recentDeliveryEvents`, `windowHours`.

## Health

`GET /v1/notifications/email/health` → `increment: I3.11`.

## UI

Notifications page — summary cards + recent delivery events list.
