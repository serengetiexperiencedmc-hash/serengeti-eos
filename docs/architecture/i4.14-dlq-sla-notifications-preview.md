# I4.14 — DLQ SLA Escalation Notifications

**Increment:** I4.14  
**Server version:** `0.54.0-pg16-i4.14`

## Summary

Open DLQ rows past the SLA threshold (`DLQ_SLA_THRESHOLD_HOURS`, default 24h from `firstFailureAt`) appear as urgent inbox notifications (`key: dlq-sla:{id}`, category `operations`, href `/commercial/events`). Gated by `events:read:dlq`. DLQ list banners remain `I4.14`.

## API

| Surface | Behaviour |
| --- | --- |
| GET `/v1/notifications` | Includes `dlq-sla:*` items when breached |
| GET `/v1/events/dlq` | Banner `I4.14` (SLA filters from I4.13) |

## UI

Events eyebrow I4.14; notifications inbox escalations for operators with DLQ read.
