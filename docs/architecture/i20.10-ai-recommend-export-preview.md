# I20.10 — Filter and export recommend last-run

**Increment:** I20.10  
**Server version:** `0.77.0-i20.10`  
**Autonomy:** Level 1 (Recommend) snapshot only. Does not record a new run.

## Summary

Filter stored last-run keys by exact match or prefix. Export the filtered snapshot as JSON or CSV.

## API

`GET /v1/ai/recommendations/last-run?key=`

`GET /v1/ai/recommendations/last-run/export?format=json|csv&key=`

Unknown `format` returns `400` (`invalid_format`). Both endpoints are read-only.

CSV columns: `occurredAt,provider,count,key`. Keys only — no PII.

## UI

- `/commercial/ai` last-run key filter
- **Export last-run** downloads CSV

## Not included

- LLM providers
- Merge, email, owner-assign, or autonomous apply
- Full recommend history
