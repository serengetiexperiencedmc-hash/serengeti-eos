# I3.23 — Allowlist dual-control digest last-run stamp

**Increment:** I3.23  
**Server version:** `0.61.0-pg23-i3.23-i4.21`

## Summary

Ops visibility into the last allowlist dual-control digest dispatch plus outbox digest analytics (mirrors I4.19).

## API

| Route | Change |
| --- | --- |
| POST `/v1/notifications/email/dispatch-allowlist-dual-digest` | Response includes `lastRun` |
| GET `/v1/notifications/email/allowlist-dual-digest-status` | `{ lastRun, analytics }` |
| GET `/v1/notifications/email/health` | Adds `allowlistDualDigestLastRun` |

## lastRun shape

```json
{
  "tenantId": "…",
  "day": "2026-08-22",
  "lastRunAt": "…",
  "lastRunByPrincipalId": "…",
  "pendingCount": 1,
  "dispatchedCount": 1,
  "skippedCount": 0,
  "recipientCount": 1
}
```

Stamped on every dispatch attempt (including `none_pending`). In-memory for now (dual-write later).

## analytics

- `outboxDigestCount` — outbox rows with key prefix `allowlist-dual-digest:`
- `outboxByStatus` — counts by outbox status
