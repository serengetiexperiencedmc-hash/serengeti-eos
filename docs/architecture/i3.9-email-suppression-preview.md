# I3.9 — SES Email Suppression / Bounce Hygiene

**Increment:** I3.9  
**Server version:** `0.43.0-i3.9-i4.8`

## Summary

Bounce, complaint, and reject webhooks add the recipient to a tenant suppression list. Subsequent email sends to suppressed addresses are skipped (`reason: suppressed`).

## Persistence

Migration `047_i39_email_suppressions.sql` — `notif_email_suppressions` with unique active email per tenant.

## API

| Route | Auth | Purpose |
| --- | --- | --- |
| GET `/v1/notifications/email/suppressions` | Bearer | List active suppressions |
| POST `/v1/notifications/email/suppressions/:id/lift` | Bearer (`notification:dispatch:email`) | Lift a suppression |

## Health

`GET /v1/notifications/email/health` → `increment: I3.9`, `suppressionCount`.
