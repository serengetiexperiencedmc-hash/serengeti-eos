# I4.13 — DLQ SLA Timers / Age Filters

**Increment:** I4.13  
**Server version:** `0.53.0-i3.16-i4.13`

## Summary

DLQ list enriches each row with `ageHours` (from `firstFailureAt`) and `slaBreached` (default threshold 24h for open statuses). Filters: `minAgeHours`, `maxAgeHours`, `slaBreached`, `slaHours`.

## API

| Route | Purpose |
| --- | --- |
| GET `/v1/events/dlq?...&slaBreached=1&slaHours=24` | Filtered list + `sla` summary |

## UI

Events — SLA breached chip; Age column.
