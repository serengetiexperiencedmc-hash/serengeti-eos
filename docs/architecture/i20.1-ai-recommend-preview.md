# I20.1 — AI recommend (read-only)

**Increment:** I20.1  
**Server version:** `0.68.0-i20.1`  
**Autonomy:** Level 1 (Recommend) only

## Summary

Add a governed AI port that turns live EOS signals into **recommended next actions**. The assistant cannot write, merge, email, or approve.

## Port (ADR-0008)

`packages/kernel/src/ai-recommend.ts` — `AiRecommendProvider`. Dev implementation is `dev-rules` (no vendor SDK). Hrefs must be `/commercial/crm|notifications|events`. Autonomy above 1 is rejected.

## API

`GET /v1/ai/recommendations`  
Permission: `ai:read:recommend` (platform admin + commercial manager).

Each item is further limited to records the caller can already read (CRM duplicates/tasks/orgs, notification outbox).

Signals: open duplicate candidates, overdue CRM tasks, missing org owners, stale allowlist digest, stale DLQ SLA digest.

Audit: allow/deny on `read:ai_recommendations` with provider name and recommendation keys (no PII).

## UI

Commercial Dashboard AI panel lists recommendations with **Open** links. No “Add to programme” write button.

## Not included

- LLM providers
- Draft (L2) or execute (L3+)
- Direct database access for AI
- Autonomous merge / email / approval
