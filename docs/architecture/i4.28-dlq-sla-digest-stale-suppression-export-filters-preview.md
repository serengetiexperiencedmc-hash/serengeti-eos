# I4.28 — Stale-audit filters / tenant export window

**Increment:** I4.28  
**Server version:** `0.91.0-i4.28`

## Summary

Filter the I4.26 stale DLQ SLA digest audit export by action and an inclusive `createdAt` window. Rows stay tenant-scoped.

## API

`GET /v1/notifications/email/dlq-sla-digest-stale/export`

| Query | Behaviour |
| --- | --- |
| `action=snooze\|ack\|cleared` | Keep matching audit rows |
| `since` / `until` | Inclusive ISO window on `createdAt` |

Unknown action returns `400` `invalid_action`. Unparseable or inverted window returns `400` `invalid_window`.

Response includes `filter: { action, since, until }`. Other tenants' audit rows are never included.

## UI

Commercial Events — action / since / until next to **Export stale audit**.
