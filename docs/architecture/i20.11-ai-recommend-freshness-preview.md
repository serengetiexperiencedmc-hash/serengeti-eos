# I20.11 — Recommend last-run freshness

**Increment:** I20.11  
**Server version:** `0.78.0-i20.11`  
**Autonomy:** Level 1 (Recommend) snapshot only. Does not record a new run.

## Summary

Mark the stored recommend last-run as stale when it is missing or older than a threshold so ops can see a missed snapshot without triggering a new recommend.

## Threshold

`EOS_AI_RECOMMEND_STALE_HOURS` (default **26** — a daily job plus slack).

Never-run counts as stale. Kernel helper: `aiRecommendLastRunFreshness` (not the notification digest env keys).

## API

| Route | Change |
| --- | --- |
| GET `/v1/ai/recommendations` | Adds `freshness` (after recording this run) |
| GET `/v1/ai/recommendations/last-run` | Adds `freshness` |
| GET `/v1/ai/recommendations/last-run/export` | Adds freshness JSON + CSV columns |

CSV columns: `occurredAt,provider,count,key,stale,neverRun,ageHours,thresholdHours`.

Last-run and export remain read-only.

## freshness shape

```json
{ "stale": true, "neverRun": true, "ageHours": null, "thresholdHours": 26 }
```

## UI

`/commercial/ai` — last-run line plus a rose banner when stale.

Dashboard AI panel — fresh/stale next to the last recommend stamp.
