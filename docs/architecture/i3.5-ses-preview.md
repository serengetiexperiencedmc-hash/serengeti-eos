# I3.5 Amazon SES Email Transport — Preview

Increment **I3.5** adds a production-oriented Amazon SES adapter alongside existing SMTP and dev-outbox paths. Tenant email templates (I3.4) apply to all adapters.

## Adapter selection

Env `EOS_EMAIL_ADAPTER`:

| Value | Behavior |
| --- | --- |
| `dev-outbox` (default) | In-memory outbox, no network |
| `smtp` / `smtp-stub` | Raw SMTP (I3.3) |
| `ses` | Amazon SES v2 API when region configured |
| `ses-stub` | Fallback when `ses` selected but region missing |

## SES env

- `EOS_SES_REGION` — AWS region (required for real sends)
- `EOS_SES_FROM` — verified sender (falls back to `EOS_SMTP_FROM`)
- `EOS_SES_ACCESS_KEY_ID` / `EOS_SES_SECRET_ACCESS_KEY` — optional; defaults to `AWS_*` env or IAM role

## Code

- `packages/kernel/src/notification-ses.ts` — config parsing
- `apps/api/src/notifications/ses-transport.ts` — `@aws-sdk/client-sesv2` client
- `apps/api/src/notifications/email.ts` — `createSesEmailAdapter()`

Health increment: `I3.5`.

## Production gate

SES sending requires verified domain/identity in AWS. Dev/Test uses `ses-stub` when region unset.
