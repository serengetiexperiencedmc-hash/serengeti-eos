# I4.5 — NATS Consumer Lag Metrics

**Increment:** I4.5  
**Server version:** `0.38.0-i3.6.1-i4.5-pg6`

## Summary

Live JetStream lag probe merged with stored tenant offset checkpoints. Powers the Commercial **Event Infrastructure** dashboard.

## API

`GET /v1/events/consumers/nats/lag` — permission `events:read:operations`

Returns:
- Stream head (`lastSeq`, message count, bytes)
- Durable consumer pending/ack-pending/ack-floor (`brokerLag`)
- Per-tenant stored offsets with staleness
- Summary status: `ok` | `degraded` | `unavailable`

When NATS is not configured, returns offsets-only with `natsConfigured: false`.

## Web UI

Route: `/commercial/events` — lag summary cards + offset table.
