# I20.5 — AI draft filters and drafts page

**Increment:** I20.5  
**Server version:** `0.72.0-i20.5`  
**Autonomy:** Level 2 (Draft). Unpublished until a human accepts.

## Summary

List drafts by **status** and **artefact type**. A dedicated **AI Drafts** page lets a human review pending, accepted, and discarded artefacts without relying on the dashboard panel alone.

## API

`GET /v1/ai/drafts?status=pending|accepted|discarded&artefactType=crm_task|crm_activity`

Unknown filter values return `400` (`invalid_status` / `invalid_artefact_type`). Response includes the applied `filters`.

Accept and discard are unchanged and still human-only.

## UI

- Overview nav: **AI Drafts** → `/commercial/ai`
- Filters for status and type
- Pending rows still show **Accept** / **Discard**
- Dashboard pending list links **All drafts →**

## Not included

- LLM providers
- Merge, email, owner-assign, or autonomous apply
- Nav badge count
