# I4.12 — DLQ Bulk Owner Assign

**Increment:** I4.12  
**Server version:** `0.52.0-pg15-i4.12`

## Summary

Assign or clear owners on many DLQ entries in one request; Events UI bulk action on selected rows.

## API

| Route | Purpose |
| --- | --- |
| POST `/v1/events/dlq/assign` | `{ ids, owner }` → `{ updated, notFound }` |

`owner: null` or `""` clears ownership. Permission: `events:replay:outbox`.

## UI

Events — bulk owner input + Assign selected alongside Replay.
