# I20.8 — Refresh pending draft nav badge

**Increment:** I20.8  
**Server version:** `0.75.0-i20.8`  
**Autonomy:** Level 2 (Draft). Unpublished until a human accepts.

## Summary

A lightweight **draft summary** endpoint returns `pendingCount` without listing artefacts. The sidebar AI Drafts badge refetches that count after a human creates, accepts, or discards a draft.

## API

`GET /v1/ai/drafts/summary` → `{ pendingCount, increment }`

Requires `ai:read:recommend`. Accept and discard remain human-only.

## UI

- Nav badges load summary instead of the full pending list
- Accept / discard / create notify the sidebar to refresh the AI badge only

## Not included

- LLM providers
- Merge, email, owner-assign, or autonomous apply
- Refreshing other nav badges from AI actions
