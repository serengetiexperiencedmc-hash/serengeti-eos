## 6. Actual figures versus estimates

For EX-09–EX-15, complete the **figure pack**:

| Field | How to fill |
| --- | --- |
| Value | Number, currency amount, percentage, or time — or leave blank if unknown |
| Period | e.g. Oct 2025 – Sep 2026, calendar 2025, last 12 months ending [month] |
| Actual / estimate / unknown | **Actual** = counted from records. **Estimate** = informed guess. **Unknown** = not available |
| Source | Where the figure came from |
| Confidence | high / medium / low / unknown |

Mark status:

- counted from records → `ANSWERED — EVIDENCE PROVIDED`
- informed guess → `ANSWERED — ESTIMATE`
- not available → `UNKNOWN` or `BASELINE = NOT YET ESTABLISHED`

Do **not** mix an actual and an estimate without saying so. If two sources disagree, use `CONFLICTING EVIDENCE` and record both.

Do **not** invent conversion rates, response times, or opportunity values.
